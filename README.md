# Better Smithing Table
I dislike the smithing table menu, so I made a mod to make it look a little better.

The binaries are available on [Modrinth](https://modrinth.com/mod/bettersmithingtable) and [Curseforge](https://www.curseforge.com/minecraft/mc-mods/bettersmithingtable).

### Branches
This branch (`main`) only contains this README.
The source code for each version of Minecraft lives on its own branch:
- `1.20`: Source code for 1.20 and 1.20.1
